# SISSÊ~KABA · Vitrine publique SOLEVO Côte d’Ivoire

Site public : https://lehito1989.github.io/sisse-kaba-APP/

La vitrine présente le projet national maïs et élevage, un comparateur de coûts local et la présentation indicative Coûts & devis MG2MIX. Les données saisies dans le comparateur ne sont pas envoyées à un serveur.

Déploiement GitHub Pages : branche main, dossier racine. Les anciens modules JavaScript internes ont été neutralisés et ne contiennent plus de données financières ou de contacts. Les modèles opérationnels et financiers doivent être conservés dans un environnement privé avec contrôle d’accès.

Les anciens commits restent accessibles dans l’historique public. Cette mise à jour ne constitue pas une suppression de l’historique.

Lancement annoncé par le porteur du projet : SELAB SHOW 2026, du 20 au 22 novembre 2026 au Parc des sports d’Abidjan, avec les segments FEED et SEED de SOLEVO-CI.
